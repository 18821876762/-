## 一、修改概述

「复制诊断信息」功能（`buildDiagnostics()` 生成的纯文本报告）原先为**扁平 `key: value` 堆砌**，复制后技术支持团队难以快速定位问题，且缺少以下关键维度：

- **系统环境** 不够直观（无浏览器/平台标识）；
- **错误堆栈** 未独立成节（DEBUG 下虽有 stack 但淹没在首行摘要里）；
- **用户操作路径** 仅单行拼成 `黑匣子(a | b | c)`，无绝对时间戳、不便于还原操作时序；
- 全篇缺少**标题块与分区**，复制体看起来像一段无结构日志。

本次修改将诊断报告重排为**「标题块 + 14 个编号分区」**结构，补齐系统环境/错误堆栈/用户操作路径/时间戳四类关键字段，保持纯文本、可直接复制粘贴。功能行为（复制动作、洞察页渲染）**完全不变**。

> 注：本次重排随 4.19.48 一并交付。4.19.48 同期还包含「视觉应答可靠性修复（熔断恢复）」，见 `docs/CHANGE_视觉应答可靠性_v4.19.47.md`（已在 4.19.48 闭环）；本文件仅记录诊断模板重排这一项。

### 2.2 `diagnostics.js` 具体变更点

**(1) 标题块 + `[1] 系统环境` 节（原顶部 `版本:` / `环境:` 两行替换）**
- 新增标题行 `网课强制续播 · 运行诊断报告` 与分隔线；
- 新增 `生成时间`（本地 `toLocaleString()`）、`采集帧`（`detectSite()` + 顶层/iframe 嵌套）、`版本`；
- `[1] 系统环境` 下新增 **`平台/浏览器`** 字段（`navigator.userAgent` 前 160 字符），便于支持团队判断脚本管理器（Tampermonkey/Violentmonkey）与浏览器环境；
- 标题块新增 **`站点` / `角色` / `本机地址`** 三项强标识（站点中文名取自 `SITES` 与内置标签表：`deepseek`=「DeepSeek 应答端控制台」、`chaoxing`=「学习通（chaoxing）· 网课核心主页」等；角色区分「应答端控制台」与「网课核心主页」；本机地址=`window.location.host`），使不同页面粘贴的诊断一眼可区分（详见 §2.2(4)）；
- 保留 `运行环境(GM存储)`、`页面状态(可见性/窗口/ready/持久化键)`。

**(2) 插入 14 个分区标题（按内容分组）**

| 节 | 标题 | 内容 |
|---|---|---|
| [1] | 系统环境 | 运行环境 / 页面状态 / 平台浏览器 |
| [2] | 续播与视频 | 视频总数 / MO 队列 / ENDED_SRCS |
| [3] | 错误堆栈 | 错误累计 + 最近 3 条（DEBUG 下含 stack 回溯） |
| [4] | 运行资源 | heap 内存 |
| [5] | DeepSeek 应答端 | 课程页探测 / 应答端就绪 / 最近请求 |
| [6] | 答题·AI作答明细 | 严格 AI 作答状态 / 逐题诊断 |
| [7] | 主循环与续播 | 主循环健康 / 轮次 / 上次 tick |
| [8] | 答题引擎 | 信号灯 / 首错 / 引擎统计 / 调度器 / MO 监控（内含子节「数据治理(桶)」） |
| [9] | DeepSeek 数据循环 | 课程页⇄GM通道⇄应答端闭环统计 |
| [10] | 性能遥测 | 续播/定向命中 / MO 走势 / tick 抖动 / 每题耗时 |
| [11] | 用户操作路径 | 原「黑匣子」重命名并逐条绝对时间戳（**恒输出**，无记录时显示「无近期操作记录」占位行） |
| [12] | 面板与配置 | 工具库项 / 面板 / 脚本弹窗 / 看播 / 接管 / 自动暂停 / 智慧树 / CONFIG |
| [13] | 视频列表 | 全量视频明细 |
| [14] | 功能自检 | 自检矩阵 partial/fail 汇总（置于末尾作为功能完整性汇总） |

> 各分区仅在原注释/单行 `L.push` 前插入 `L.push(''); L.push('■ [n] ...');`，**未改动任何数据采集逻辑**（含跨帧聚合、bestEffort 守卫、DEBUG 分支）。

**(3) `[11] 用户操作路径`（原 `黑匣子` 单行 → 逐条绝对时间戳）**
- 原输出：`黑匣子(最近N): 12s前·play·视频#1 | 8s前·seek·driftGuard`（单行、相对时间）；
- 新输出：每一条操作独立成行，带 **`toLocaleTimeString()` 绝对时间**：
  ```
  ■ [11] 用户操作路径（黑匣子·最近N条）
    - 14:02:11 · play · 视频#1
    - 14:02:19 · seek · driftGuard
  ```
- 数据源不变（`cxMetricsSnapshot().bx` 黑匣子缓冲），仅渲染方式变化。
- **恒输出（v1.1 修订）**：本页无任何操作时不再省略整节，改为输出占位行 `  - 无近期操作记录`，保证编号 `[1]→[14]` 严格连续、无跳空。

**(4) 分区相关性标注 `_sec(n, name)`（v1.2 · 页面区分）**
- 新增 `_sec(n, name)` 辅助：按 `detectSite()` 结果给页面相关分区追加相关性标签，使学习通 / DeepSeek 等不同页面的诊断重点一眼可辨。
- 映射（`_relMap`）：
  - `deepseek`：`[2] 本页无视频`、`[5] 本页核心`、`[6] 本页无关`、`[8] 本页无关`、`[9] 本页核心`、`[13] 本页无视频`；
  - `chaoxing` / `zhihuishu`：`[5] 跨页参考`；
  - 其他站点：无标签（默认全量输出）。
- 效果示例：DeepSeek 页标题块 `站点: DeepSeek 应答端控制台 / 角色: 应答端控制台 · 广播 DS 登录态…`，`[2] 续播与视频（本页无视频）`、`[6] 答题·AI作答明细（本页无关）`；学习通页 `站点: 学习通（chaoxing）· 网课核心主页`，`[5] DeepSeek 应答端（跨页参考）`。

**(4) `[3] 错误堆栈` 节**
- 错误 stack 早在 `utils.js:30` 的 `swallow` 已存 `e.stack`，诊断头部（DEBUG 下）原本就读取 `_r.stack` 打印最近 3 条；本次仅将其**独立成 `[3]` 节**并保留原逻辑。

### 2.3 未变更项（明确声明，避免误读）

## 三、修改原因及影响范围

### 3.1 修改原因
1. **可读性**：扁平文本复制后难以快速定位，分区 + 编号提升扫描效率；
2. **完整性**：补充浏览器/平台标识，支持远程排障；
3. **可溯源性**：用户操作路径从单行相对时间改为逐条绝对时间，便于还原「用户做了什么 → 触发了什么」；
4. **错误定位**：错误堆栈独立成节，DEBUG 下 stack 回溯更醒目。

### 3.2 影响范围
- **运行时影响**：无。仅在用户点击「复制诊断信息」或洞察页渲染时生成文本，性能与内存无变化；
- **契约影响**：无。`_sim` 中无断言诊断文本格式的契约测试（已搜索确认 0 命中），重排不破坏任何门禁；
- **外部依赖**：无。复制体仍可被粘贴进工单/聊天，结构变化对人类读者更友好，对机器解析无既有依赖；
- **兼容性**：旧版诊断文本消费者（人工阅读、粘贴工单）完全兼容新格式。

### 3.3 风险与缓解
- 风险：若未来有脚本/人工正则解析旧诊断格式，会因结构变化失效 → 经核查无此类消费者；
- 缓解：分区标题使用稳定前缀 `■ [n]`，如需机器解析可据此锚定。

## 五、后续注意事项

1. **格式变更提示**：若后续有工具（如自动工单解析、日志采集）依赖诊断文本，须按新分区标题 `■ [n]` 锚定，而非旧 `key: value` 首行格式。目前无此类依赖。
2. **隐私面**：新增 `平台/浏览器` 为 `navigator.userAgent`（常规诊断信息，不含账号/密钥/题目内容），符合既有诊断数据脱敏原则；若日后需进一步脱敏，可截断 UA 长度或哈希。
3. **黑匣子恒有节**：`[11] 用户操作路径` 已改为**恒输出**——用户产生页面操作（play/seek/切换等）时逐条显示绝对时间；稳态挂机/无操作时显示占位行「无近期操作记录」，不再整节缺失，保证分区编号 `[1]→[14]` 连续。
4. **DEBUG 下错误堆栈**：`[3]` 节最近 3 条 stack 仅在 DEBUG 构建/开关下展开（与既有行为一致），发布版仅显示 msg 摘要。
5. **版本追溯**：本重排随 4.19.48 交付；与同版本的「视觉应答可靠性修复（熔断恢复）」为并行独立变更，分别见本文件与 `docs/CHANGE_视觉应答可靠性_v4.19.47.md`。
6. **勿新增临时文件**：任何后续验证脚手架请放入 `_ninja_test/`，禁止在仓库根目录创建临时脚本后用 `delete_file` 清理（既有事故教训）。
