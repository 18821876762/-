# 变更记录入口

用户脚本元数据中引用的 v3.x–v4.17 历史日志已完整保存在 [旧版 CHANGELOG](../旧文档/03_任务计划与变更/docs/CHANGELOG.md)。该原件保留当时的版本、日期和结论。

## 2026-10-14：4.20.3 安全与发布修正

- API Key 改为管理器私有存储并绑定明确的端点 Origin；公开配置不暴露凭据，配置导出/导入过滤凭据字段及含当前密钥的普通值。
- AI 请求在异步读取凭据后再次核对原任务代次、页面和取消信号；停用、卸载或恢复新任务后不能继续发送旧请求。
- Python 桥限制可信来源，禁止查询参数传递 token，非回环监听必须鉴权；不同服务实例隔离配置。
- 统一自有代码 MIT 许可，为独立脚本附完整许可通知；替换真实页面捕获，脱敏共享归档副本，原件留在本机忽略快照。
- CI 构建 personal/open/latest，浏览器核验同次构建及许可通知；增加提交来源、文件清单和本地发布包预检。
- 为自动生成契约固定 LF，避免 Windows 新克隆因换行转换误报文档漂移。
- 本次验证范围、结果和发布边界见 [4.20.3 记录](releases/4.20.3.md)。

## 2026-10-10：4.20.2 源码模块拆分

- 将 14 个超过非白名单硬限制的模块按配置、调度、答题、导航和面板职责拆为连续源片段；源码由 64 增至 107 个文件，构建清单由 62 增至 105 项。
- 以完整拼装语法树核对运行逻辑，除显示版本常量外与拆分前相同；保留原函数闭包、声明次序和执行次序。
- 跨模块契约改按构建顺序解析真实词法作用域，契约语义检查和仿真读取完整源组；增加源组及异常清单回归。
- 不增加体积白名单，原 DOM 模块例外继续保留。更新源码镜像、分发产物与维护说明；快照、映射及最终验证见 [拆分记录](../backups/refactor/2026-10-10/module-split/拆分说明.md)。

## 2026-10-07：4.20.1 功能修正

- 验证控件遍历全部匹配项，按元素与祖先样式判断可见性，修复隐藏首项漏检和透明/隐藏控件误停机。
- 核心桥绑定运行令牌和页面身份，取消在途请求与迟到结果；同源帧共享请求协调，各帧保留自己的章节与目标消费。
- 独立逆向服务仅解析明确答案句、字段与选项令牌，支持 A–Z、多选去重，冲突与不确定结果不猜测。
- 更新浏览器桥测试的实际合同，增加安全可见性及桥状态回归，并接入统一测试和 CI。
- 更新 personal/open/latest、源码镜像、使用说明和契约。修正前快照及本次验证见 [修正记录](../backups/fixes/2026-10-07/functions/修正说明.md)。

## 2026-10-04：4.20.0 核心状态机重写

- 增加 CoreState 五态控制器，统一自动化许可、作用域取消和单调代次；同源子帧服从父帧停机。
- 停机、停用和卸载后，播放重试、AI / 视觉回传、延迟扫描与导航不再继续执行；恢复不能复活旧任务。
- 答题区分已提交、待确认、待复核和 AI 在途；低置信答案等待人工确认，保存草稿不计完成。
- 自动下一课实现可取消三态流程，修复开关关闭后动作、失败重试、同元素换源和桥清单契约。
- 开源版预热使用成对 GM 读写或 localStorage，恢复 armed 状态并取消过期提示；补齐 GM_getValue 授权。
- 更新 personal/open/latest、源码镜像、契约与回归。设计与验证范围见 [核心状态机](CORE_STATE.md)，旧版本快照及日志见 [重写记录](../backups/refactor/2026-10-04/core-state/重写说明.md)。
