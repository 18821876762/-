6 · 反馈分级矩阵

解决"操作反馈全靠 toast 刷屏"：状态类变化只更新常驻 UI，不再发 toast。

操作后果反馈渠道实例
即时可逆的小操作toast info · 1.5s暂停成功、速率已设
状态持续变化常驻 UI 自更新，不弹 toast视频列表翻转、滑块显值
影响后续流程toast warn + 状态区落一行单视频模式已开
失败 / 异常toast error + 写入近期错误命令执行出错
破坏性操作confirm 二次确认清空黑匣子、重置配置
